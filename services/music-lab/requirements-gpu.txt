# ACE-Step 1.5 (official repo: https://github.com/ace-step/ACE-Step-1.5).
# Upstream pins torch==2.10.0+cu128 and vendors nano-vllm under
# acestep/third_parts/nano-vllm, which is NOT published on PyPI. Installing the
# project normally would therefore replace the host torch and fail to resolve
# nano-vllm. Install the package with --no-deps (the runtime deps are listed
# above) using the verified command:
#
#   pip install --no-deps -r requirements-ace-step.txt
#   # or: pip install --no-deps "ace-step @ git+https://github.com/ace-step/ACE-Step-1.5.git@main"
#
# The pipeline auto-downloads checkpoints from
# https://huggingface.co/ACE-Step/Ace-Step1.5 into $ACE_STEP_MODEL_PATH
# (override with ACE_STEP_AUTO_DOWNLOAD=false + a pre-populated directory).
# The 5Hz LM backend "vllm" additionally needs nano-vllm; the adapter defaults
# to ACE_STEP_LM_BACKEND=pt and ACE_STEP_USE_LM=false (DiT-only).
#
# Optional quantization (ACE_STEP_QUANTIZATION=int8_weight_only, etc.) needs
# torchao, which is intentionally NOT installed by default. Install it
# separately if you enable that feature: pip install "torchao>=0.16,<0.17".
